# “复现”具体包括什么

**可复现的是公开代码、执行协议、参数和输入锁定的方法。** 个人原型、原作品、已审对白、声线、原小说及模型权重不在仓库。没有它们，不能原样重现私人影片或历史基准画面；同seed也不是跨版本、跨GPU的逐像素保证。

## 三个验证层级

1. **核心烟测**：干净克隆、editable安装、`localvideo doctor`、新目录`demo`。应得到5秒/80帧测试视频、测试音、字幕、带输入SHA和音频覆盖检查的技术回执。不会调用AI或网络模型。此层由自动化测试覆盖。
2. **真实模型技术链**：依INSTALL装独立环境，锁上游commit、依赖和模型SHA；准备自有合法参考，按WORKFLOW执行单镜头，再混音/合成，记录所有失败。源/节点schema不相容时先修适配，不偷偷换模型后沿用旧标签。
3. **创作质量**：审核身份、动作/道具顺序、静听嘴部、跨镜一致、真实人耳自然度。没有看/听过，就写未验证；不能由层1/2的退出码、ASR或哈希推导通过。

## 每次运行保存

```text
project/                # 你的源码、版本与审核文档
  run-config.json
  inputs/               # 元数据索引，不随仓库发布私人素材
  workflows/
  provenance/
    ownership.json
    model-lock.json
    phases.jsonl
    jobs/               # prompt_id/history/真实步骤/计时/失败
media/                  # 私有输入、native、最终MP4/声音
work/                   # 本次服务临时目录
hot/                    # 可选热副本，绝不是永久模型唯一原件
```

四个目录是相互独立的新根；永久`model_library`另外保存。目录可以分盘，也可以同盘分离；路径完全参数化。原有文件不覆盖。Windows句柄/断电恢复、所有旧脚本的FileID假设不在跨平台代码的保证内。

## 执行覆盖与限制

本仓库发布测试应在独立目录进行：Python编译、JSON与Markdown内链、CLI帮助、CPU demo完整解码、输入SHA失配/音频越界/路径覆盖等负例、初始化隔离模式、loopback服务限制。CI在Linux/Windows跑核心测试；GPU推理、模型下载、视听质量和上游安装需要单独环境，不由CI绿勾冒充通过。

`configs/upstreams.lock.json` 固定历史源版本；`configs/models.json` 固定五个Wan文件哈希及下载版本。它们不是所有外部系统的完整锁：GPU驱动、PyTorch/Sage/Triton、FFmpeg编译配置与字体必须在自己的回执里另记。上游权重可能下架/需授权，遇到不能下载时应报告，不宣称可保证永久获取。

贡献复现报告请使用合成/自有可公开素材，并去掉绝对私人路径/用户名/声纹/令牌。不要把自己的整机清单或私人作品直接贴到issue。
