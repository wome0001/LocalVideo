# 存储、缓存和恢复

目录按角色分离，不绑定盘符：

- 永久环境/工具/模型原件：独立tools与model_library。
- 项目源码、工作流、分镜、字幕、审核和运行回执：project元数据根。
- 私有图片、音视频、latent与最终媒体：artifact_root。
- 模型热副本/高速临时：hot；普通服务中间件：work。

按原项目约定可以把元数据、永久媒体和热副本分放不同盘，但hot不是模型唯一原件。先退出属于本任务的进程，核永久原件SHA，再逐项清热副本；不能照着盘符递归删目录，不碰系统分页。

不可再生的人像、已审对白和付费原片需要独立备份。两目录、硬链接或符号链接不算独立容灾；同seed重跑也不保证相同字节。未确认恢复条件时不要删除唯一副本。公开包不包含某台机器曾接受单份风险的授权，也不推定下载者接受同样风险。

搬运旧项目应复制→刷盘→SHA读回→建立迁移索引→核恢复能力/授权→再删除旧数据，必要时保留旧路径链接。链接只提供兼容，不证明所有依赖旧FileID/真实盘符边界的冻结脚本都能重跑。历史审核文件不改字节，路径变化另加索引。
