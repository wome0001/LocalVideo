## 能直接复用的做法

1. 先低清短样；审核图片/分镜/音轨后才扩批。复用批准的道具/空镜和没变的镜头，少做无用推理。
2. 一个GPU队列；按兼容模型批次复用静态编码/装载。不能把Sampler缓存命中当新采样提速。
3. 蒸馏LoRA与步数/调度器匹配；FP8/NVFP4/Sage/编译各核真实支持，不按显卡代际猜参数。避免同时换五个变量。
4. 降低卸载/重复校验/重复编码成本。CPU原权重复用hook只对锁定Wrapper版本、推理/eval、未合并LoRA、blocking、无prefetch/compile配置测试。默认关闭；可变buffer仍走原 `.to()`。
5. 先保留原生低fps/尺寸记录，插帧/升清单列。避免在多个阶段反复有损编码。

对照每组至少两次**不同prompt_id、真实执行的暖任务**，冻结模型/LoRA/精度/输入SHA、seed、步数、帧数、尺寸和fps。`tools/benchmark_report.py` 拒绝重复回执、缓存/未证明采样和不等设置；只有速度表不能证明画质。`compare_native.py` 提供完整RGB/PTS比较，审查动作、静听、身份和听感另做。

Windows参考内核ABI为SageAttention `2.2.0+cu128torch2.7.1.post3`、triton-windows `3.3.1.post21`。这不是所有显卡推荐安装组合；从合法上游获取匹配wheel，切勿从不明网盘下载二进制。模型源和源码版本见 configs。
