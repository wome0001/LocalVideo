# 路线图：能力、状态和选择

以下是截至2026-11-24的**特定历史版本测试摘要**，不是所有版本的排名。模型原生能力和本仓库自动化覆盖分开。新版本按官方入口重新核验。

| 路线 | 输入/输出 | 本仓库提供 | 历史边界 |
|---|---|---|---|
| Wan2.2-S2V / Wrapper | 参考图+已有语音→视频 | 主线模板、源锁、服务/异步任务、实时步骤/计时、可选CPU权重复用、剪辑工具 | 具体FP8/LCM/LoRA组合有已审片段；不保证任意角色/动作 |
| FreeVideo/H3 | 文本/多种参考→视频 | [接入与二采流程](routes/freevideo.md)、通用Comfy API客户端 | guide口齿偏软、上半脸近固定；自然度/音素审核未全部完成 |
| SVD-XT | 图→静音视频 | `tools/svd_generate.py`、[安装与实验](routes/svd.md) | 特定轻动作肖像受限通过；入画/医院运动拖影失败，不承担对白 |
| LTX-2.3原生AV | 版本支持的图/文/音→AV | [版本边界与上游接入](routes/ltx-contentv.md) | 历史4候选伪字幕失败，末样口闭而音频继续；不是对所有LTX版本的否定 |
| ContentV-8B公开接口 | 文→静音视频 | [上游安装/试验步骤](routes/ltx-contentv.md) | 无指定图/音频条件；第二动作门槛失败，不替代I2V/对白 |
| Blender Cycles/Eevee | 场景/动画脚本→帧/视频 | 程序化产品参考脚本、[渲染路线](routes/blender.md) | 完全可控的几何/灯光/镜头；脚本不能自动获得真人身份/表演 |
| LivePortrait / MuseTalk / LatentSync | 人像/驱动/语音→局部动画 | [可选人像与口型步骤](routes/portrait.md) | 原型相似、静听闭口和口部清晰必须逐镜审，不默认主线 |
| 音乐 / 歌声 | 文本/曲谱/参考→音乐 | [工具选择与混音](routes/music.md) | 支持语音不等于会唱歌，支持歌曲不等于能稳定整曲；分别验 |

Wan CPU权重复用、模型低精度、分镜复用和更低步数是不同维度，不混写成同一种提速。S2V是“给定声音驱动视频”，不是“模型凭剧本生成自然多角色对白”。LTX原生AV也不免除台词/口型/伪字幕审核。

各官方入口与许可见 [第三方说明](../THIRD_PARTY_NOTICES.md)。只有 Wan 主线、CosyVoice2、SVD 与 Blender 有本仓库专门执行代码；其余是明确标注的接入/实验配方，经上游工具运行，不假装一个CLI统一支持全部模型。适配新版本欢迎带环境锁、失败样本说明和自有/合成素材测试，勿提交私人作品。
