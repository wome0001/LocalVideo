# 公开边界与素材安全

仓库仅分发原创通用源码、技能、参数模板和文档。**不分发**人物原型、已审/克隆声音、私人小说内容、成片/验收抽帧、付费原片、模型权重、机器磁盘盘点、聊天记录、API key和账号凭据。

`.gitignore` 只是第一层保护；`tools/check_public_tree.py` 还会检查源码树中的文件类型、大小、重解析点、典型凭据和私人用户名路径。人物/作品名称、授权范围与间接身份信息仍需人工或独立代理审文本。CI仅使用合成数据。发布者必须再审暂存树和所有将公开的Git历史；忽略规则不能从已有提交中移走秘密。

真实任务输入/输出使用repo之外的工作根。音轨与人像参考按授权使用，不将可识别声纹放进错误日志/测试包。模型下载单独进行并遵守许可；LocalVideo不需要任何云模型key。若未来接云端，仅通过环境变量读取、默认关闭，审费用和数据流向后再使用。

程序化CPU烟测会生成测试卡、测试音和MP4，都是临时运行产物，也不提交到本仓库。用户下载后可自行运行得到它们；本项目不以私人成片做宣传。

发现凭据泄漏请立即撤销/轮换，使用GitHub私密安全通道联系维护者；不要在公开issue重复贴出密钥。只删文件或只新增.gitignore不能消除Git历史泄漏。
