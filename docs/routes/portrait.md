# 可选：LivePortrait、MuseTalk、LatentSync

官方入口见THIRD_PARTY_NOTICES。分别用独立环境，按上游示例输入格式运行；不要共享不兼容的torch/face-analysis依赖。检查基础人像、驱动视频、脸部检测和各额外模型的许可。

1. 先做2–3秒同角度近脸，比较原型与动画的眨眼、转眼、开口；不要只看静态第一帧。原型/侧脸和关键动作先审。
2. LivePortrait主要是驱动表情/头部，不是完整肢体表演或自动精确语音嘴型。MuseTalk/LatentSync以已有批准音轨修嘴型，不能修复所有身份、脸颊暗块或手部错误。
3. 以最终音轨实际发声区间驱动；静听/说完后的头嘴保持合理，眼睛可自然反应。检查句首、强音、转折、句尾和静默，多帧/实时看片。
4. 输出新版本，保留原片对照和源SHA；不要改掉原生帧时钟再声称修复链能原样继承。
5. 新人脸/角度/裁切须重算mask和跟踪。审核不通过就回到分镜/源图，不在旧底片上无限打补丁。

这是辅助方案，历史近脸也出现身份不符和口部模糊失败；当前不替代Wan主线，不承诺用任意原型照就能得到合格短剧。
