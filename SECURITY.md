# Reporting a security issue

Do not attach credentials, reference photos/voices, private generated work, environment dumps or unsanitized logs to a public issue. Revoke exposed credentials immediately. Use GitHub's private vulnerability reporting when available or contact the maintainer privately through an available GitHub channel.

LocalVideo is workflow code. Only run trusted model files and reviewed upstream nodes; arbitrary Python custom nodes execute code with your user permissions. ComfyUI runners bind to loopback. This is not a hardened multi-tenant service.

Public releases require a source/privacy/provenance check and an independent reviewer. Tests generate synthetic temporary files. No credential store, cloud generation key or private media is bundled.
